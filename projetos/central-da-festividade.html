WebTempo real

Repositório privado — disponível para demonstração sob solicitação.

O que faz

Aplicação web para organizar festividades de igreja em tempo real — programação, louvores, escalas de voluntários, avisos, cadastro de visitantes, pedidos de intercessão e relatórios, com painel de dirigente atualizado ao vivo via Server-Sent Events.

Para quem é

Igrejas que promovem festividades/eventos com múltiplos dias, voluntários escalados e recepção de visitantes.

Status

Em produção — documentação completa de deploy, checklist de produção e testes automatizados com CI.

Stack técnica

  • Next.js 16 (App Router)
  • React 19
  • TypeScript
  • Tailwind CSS
  • PostgreSQL com Prisma ORM 7
  • Server Actions + SSE
  • Vercel + Supabase

Principais funcionalidades

  • Cadastro de festividade com PIN de recepção e de dirigente
  • Agenda de cultos únicos ou recorrentes
  • Escalas com link de confirmação por voluntário, sem conta
  • Painel de dirigente ao vivo (púlpito)
  • Cadastro de visitantes com exportação CSV segura
  • Pedidos de oração/intercessão
  • Auditoria de todas as ações sensíveis
  • Backup e restauração via JSON

Diferencial

Pensado para operar por PIN sem exigir conta de cada voluntário/visitante, reduzindo fricção de adoção em eventos de igreja.
