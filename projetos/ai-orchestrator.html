O que faz

CLI que orquestra três agentes de IA (Antigravity planeja, Codex implementa, Claude revisa) em um fluxo com aprovação humana obrigatória entre cada fase, evitando que agentes disputem arquivos ou aprovem o próprio trabalho.

Para quem é

Desenvolvedores que usam múltiplos agentes de codificação no mesmo projeto e querem rastreabilidade e controle.

Status

Em produção, distribuído via GitHub com manual completo em PDF.

Stack técnica

  • Shell/Bash puro
  • Linux
  • Integra as CLIs oficiais agy (Antigravity), codex e claude

Principais funcionalidades

  • Fluxo planejar → implementar → revisar → validar achados → corrigir
  • Aprovação humana obrigatória em cada gate
  • Relatórios detalhados por execução em .ai-runs/
  • Escrita restrita ao workspace do projeto
  • Revisor sem ferramenta de edição (só leitura/diagnóstico)
  • Nunca executa commit, push, merge ou deploy sozinho
  • Comando off interrompe o fluxo preservando artefatos gerados

Diferencial

Único orquestrador do portfólio pensado para múltiplos provedores de IA simultâneos com controle humano explícito em cada transição.
