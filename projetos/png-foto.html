PNG Foto / Fundo Fora

Privado MVP / Funcional

Remoção de fundo on-device, sem upload de imagem.

MobileOn-device

O que faz

App que remove o fundo de fotos diretamente no aparelho (sem enviar imagem a servidor), exportando PNG-32 com canal alpha real, usando o modelo U²-NetP via ONNX Runtime.

Como funciona

  1. Usuário abre a foto do produto no app

  2. Seleciona a pessoa ou objeto a manter

  3. Modelo U²-NetP remove o fundo direto no aparelho

  4. Usuário ajusta a borda com feather

  5. Exporta o PNG com transparência, pronto para anunciar

Principais funcionalidades

  • Recorte de fundo on-device (pessoa e objeto)
  • Exportação PNG com alpha e feather de borda
  • Plano Free (3 recortes/dia) e Pro (ilimitado, até 4K, pincel fino, lote)
  • Paywall só após o primeiro uso bem-sucedido
  • Testes automatizados de composição PNG e do contador diário

Diferencial

Privacidade real — nenhuma foto sai do celular, sem conta e sem marca d'água, ao contrário da maioria dos concorrentes que processam na nuvem.

Para quem é

Vendedores de marketplace, artesãos, lojas de roupa e pequenos negócios que precisam de fotos de produto rápidas para anúncio.

Stack técnica

  • ONNX Runtime (WASM)
  • Modelo U²-NetP (Apache 2.0)
  • Kotlin (módulo Android nativo)

Status

MVP funcional na versão web on-device; módulo Android nativo pronto para build (AAB) rumo à Play Store.
