SlideRevive Church AI

O PDF da pregação vira slides para o telão.

Importe o PDF ou o PowerPoint recebido e receba slides 16:9 prontos, com o tema escolhido pelo conteúdo — processado no navegador, sem enviar o arquivo.

MVPCódigo privadoWebPrimeira versão
Pedir uma demonstração

Código privado — demonstração sob pedido. Primeira versão, ainda não testada com equipes de igreja.

7temas prontos
25 MBtamanho máximo do arquivo
100páginas ou slides por arquivo

Conferido no código e no README do repositório privado em 24 set 2026.

Prova de entrega

O que já funciona hoje

Já entregue

  • Importa PDF, PPTX e PPSX até 25 MB
  • Lê o texto localmente e escolhe o tema pelo conteúdo
  • Editor de slides com duplicar e arrastar para reordenar
  • Modo apresentação em tela cheia
  • Exporta de volta para PowerPoint
  • Botão para apagar os dados salvos no aparelho

Como está construído

  • Next.js e TypeScript, com Zustand e Framer Motion
  • pdfjs-dist lê o PDF dentro do navegador
  • Primeira versão em 29 ago 2026

Antes do culto

Do arquivo recebido ao telão

  1. ImportaAbre o PDF ou o PowerPoint da pregação.

  2. LêO texto é extraído no próprio navegador.

  3. MontaOs slides 16:9 saem com o tema escolhido.

  4. RevisaA equipe reordena e ajusta.

  5. UsaApresenta direto ou exporta para PowerPoint.

Por que o SlideRevive

Preparar a projeção mais rápido

Complementa o Lúmen

O SlideRevive prepara o material; o Lúmen projeta ao vivo.

O arquivo não sai do computador

Tudo é processado no navegador, sem upload.

Volta para o PowerPoint

Exporta em .pptx ou .ppsx para quem usa outro programa.

Em vez de copiar o texto da pregação slide por slide: importe o arquivo e só revise.

Ainda não definido

Para quem é
Equipes de mídia de igreja que recebem a pregação em PDF ou PowerPoint e precisam adaptar para o telão.
Como usar
Abre no navegador; os arquivos ficam no próprio aparelho.
Tecnologia
Next.js, React, TypeScript, Zustand, Framer Motion e pdfjs-dist.
